# КП на бегу

Локальный редактор коммерческих предложений на React и TypeScript. Данные черновиков хранятся в IndexedDB текущего браузера; сервер и авторизация не требуются.

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте адрес, который покажет Vite. Для проверки используйте `pnpm test` и `pnpm build`.

## Возможности

- Создание и редактирование нескольких черновиков с автосохранением.
- Добавление позиций вручную и импорт CSV с предварительной проверкой.
- Пересчёт стоимости каждой позиции и общей суммы без НДС.
- Предпросмотр фирменного бланка и сохранение PDF через печать браузера.
- Экспорт и импорт черновика в JSON для переноса между устройствами.

CSV должен содержать колонки `Наименование`, `Ед. изм.`, `Количество`, `Цена`, `Срок поставки, дней`. Образец скачивается в редакторе. Допустимы `;` или `,` в качестве разделителя; дробные числа можно записывать с запятой.

При сохранении PDF выберите «Сохранить как PDF» в диалоге печати браузера. Макет рассчитан на формат Letter, как предоставленный образец. Проверьте печать на своём браузере перед отправкой документа клиенту.

Черновики привязаны к браузеру и устройству. Очистка данных сайта удалит их; для резервной копии используйте экспорт JSON.
